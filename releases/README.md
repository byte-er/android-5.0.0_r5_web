# Android 5.0 for the web: release builds

Both builds are generated by `web/tools/build.mjs` from this AOSP tree (see
[`../web/README.md`](../web/README.md)).

| Build | How to run | Contents |
| --- | --- | --- |
| `android-5.0-web-standalone.html` | Double-click it. A single self-contained file that works offline from `file://`. | Everything inlined. Pico voice: English (US). A subset of the ringtones and alarms. |
| `android-5.0-web/` | Serve the folder over HTTP(S), e.g. `python3 -m http.server --directory android-5.0-web 8080`, then open http://localhost:8080. Installable as a PWA and works offline after the first load. | All six Pico voices (en-US, en-GB, de-DE, es-ES, fr-FR, it-IT), the full Material sound set and all MIDI files. |

## Installing apps (.wapk)

`wapk/com.cxinventor.file.explorer-2.7.6.wapk` was converted from the CX File
Explorer 2.7.6 APK with `web/tools/apk2wapk.mjs`. Its package name, version,
label and icon come from the APK. The APK's Dalvik code can't run in a browser,
so the app itself is a web file explorer written for this port (see
`web/docs/WAPK.md`).

1. Enable Settings › Security › **Unknown sources**.
2. Install the file using any of these:
   - drag it onto the page;
   - Settings › Apps › ⋮ › *Install app from file (.wapk)*;
   - for the folder build, open `android-5.0-web/?install=../wapk/com.cxinventor.file.explorer-2.7.6.wapk`.
3. Tap **Install**, then **Open**. The app also appears on the home screen.

## Controls

On a desktop the phone is drawn in a device frame and can be driven with the
mouse. On a phone it runs full-screen with touch.

| Key | Action |
| --- | --- |
| Esc | Back |
| Alt+H or Home | Home |
| Alt+R or End | Overview (recents) |
| Alt+N | Notifications / Quick Settings |
| Alt+P (hold) | Power button (hold for the power menu) |
| PgUp / PgDn | Volume |

The side buttons on the device frame work too. Some things to try:

- Swipe down from the status bar twice for Quick Settings.
- Long-press the home screen for wallpapers and widgets.
- Settings › Language & input › Text-to-speech output › *Listen to an example*
  runs the Pico TTS engine as WebAssembly.
- Music › MIDI plays MIDI files through the Sonivox synthesizer as WebAssembly.
- Settings › About phone: tap *Android version* three times, tap the circle
  five times, then long-press it to play LLand.
- Settings › About phone: tap *Build number* seven times to unlock developer options.
